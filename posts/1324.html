The worst thing a startup founder can link is that faux-leather design vibe by Claude code design. Doesn’t matter if it’s a deck, a site, some tiny landing page. First thing you want to do is close it.

Don’t know about you, but I can tell from the first scroll.

Let me explain:
- nobody read the content, almost certainly — it’s abstract phrases, ambiguous wording, and so on
- waaaaay too much stuff, and in tiny font
- there’s almost never any thought-through narrative
- but the most important thing is: the industry is allergic to this
- oh right, and there are people who use
this kind of thing
as a browser plugin
