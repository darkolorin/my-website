A bit about the future of SaaS, personal assistants inside the system, and AI for this whole thing.
Claude Code agent dropped recently and Cursor started hyping hard last year. These are basically as close as it gets to automating the system (you can call them agents), the kind of stuff that helps you write code or, essentially, be a programmer of features. Last summer I was already pretty easily making Telegram games as an experiment without touching a single line of code with my hands. Back then people didn’t really believe it. Then the quality of the base coding models started going up and it became possible to build pretty complex prototypes.

What I’m saying is: right now it’s totally realistic to make yourself a web app or a simple game with zero programming knowledge and be happy. Yeah, it’ll be a bit sweaty along the way, but it’ll work out.

So I think that at the current pace of progress in automating the programming process, you’ll easily be able to write yourself any basic interface for whatever. Like, you need to learn English tomorrow using some method you saw on TikTok, you open an assistant (soon even a system-level one) and go: hey, make me a learning app with flashcards and also so I can instantly search for movie clips where this word shows up. And the assistant will put that app together for you. Same thing with all sorts of SaaS for small businesses. You’ll be able to just say: hey, make some A/B tests on the buy buttons and show the results and maybe even pick what, according to the data, actually works on my audience.

That’s where I see a big bet on Anthropic and Cursor. Automating engineering effort, for now, looks like the most real thing.

Немного о будущем SAAS, персональных ассистентов в системе и AI для всей этой штуки.
Недавно вышел Claude Code агент и в прошлом году начал очень сильно хайпить Cursor. Это все такие максимально близкие к автоматизации системы (агенты можно назвать), которые помогают вам писать код или быть по сути программистом фичей. Я еще прошлым летом достаточно легко писал игры для телеги в качестве эксперимента не трогая руками ни одной строки кода. Тогда все не особо верили. Потом качество базовых моделей для программирования стало расти и стало возможно писать вполне сложные прототипы.
Что я хочу сказать, что сейчас вполне реально без знаний программирования сделать себе самому веб приложение или простую игру и радоваться. Да, будет чуть чуть потно по пути, но получится.
Так вот я считаю, что с текущим темпом прогресса в автоматизации процесса программирования вы сможете легко написать себе любой базовый интерфейс для чего-то. Например нужно завтра изучить Английский каким-то методом, который вы увидели в тиктоке, открываете ассистента (в скором времени даже системного) и говорите: а сделай мне приложение для изучения с карточками и вот чтобы еще можно было сразу искать отрывки кино где это слово. И ассистент вам соберет такое приложение. Тоже самое касается и всяких saas для небольших бизнесов. Вы сможете просто сказать: а сделай плиз а/б тесты на кнопки покупки и покажи результаты и может даже выбери что по данным там работает на моей аудитории.
В этом я вижу большую ставку на Anthropic и Cursor. Именно автоматизация инженерных усилий пока что кажется самой реальной.
